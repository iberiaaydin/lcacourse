Sensitivity: which input really matters?

A model is sensitive toward a parameter if a small change in this parameter results in a large change in the model result. It is insensitive toward a parameter if any change in this parameter has no (or negligible) effect on the result – which may indicate that the parameter is not needed, or at least is not an important input for this particular value of the model result.

A small LCA model: the carbon footprint of 1 kg of greenhouse tomatoes. Move the sliders and watch how much the result moves. One input changes the result drastically, one hardly at all, the others are in between. Then switch the scenario and see that sensitivity depends on where the model is operating. One-at-a-time analysis: change one input, keep all others as they are now. Sensitivity coefficient S = (Δresult / result) ÷ (Δinput / input) – the % change of the result for a 1 % change of the input.

In this linear model each input's sensitivity coefficient equals its share of the result. That is why the input that dominates the result is also the one the result is most sensitive to – and why a sensitivity analysis tells you where better data are worth the effort.
