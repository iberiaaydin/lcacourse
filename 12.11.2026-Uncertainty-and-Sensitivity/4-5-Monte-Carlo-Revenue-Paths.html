Monte Carlo over time: simulated revenue paths

An online shop in Türkiye wants to know how much revenue the next month may bring. Nobody knows the shop's true average visitors, conversion rate (share of visitors who buy) and order value exactly – each is described by a distribution. A simulation run draws one possible set of these averages and then simulates every day with some day-to-day noise on top. One run gives one possible path of cumulative revenue; many runs show every possible outcome – and how likely each is. The same idea applies to an LCA over a product's lifetime. The model

The distributions describe how uncertain each average is – one value is drawn per run. Day-to-day noise then lets every day vary around that average (± the chosen % as one standard deviation) – it makes the lines wiggle.

Which input drives the spread?
